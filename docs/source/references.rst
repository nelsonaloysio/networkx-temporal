References
##########

This package interacts with or is built on top of the following libraries:

- `CuGraph/CuML (RAPIDS) <https://docs.rapids.ai/api/>`_ [1]_
- `CuPy <https://cupy.dev>`_ [2]_
- `Deep Graph Library <https://www.dgl.ai>`_ [3]_
- `DyNetX <https://dynetx.readthedocs.io>`_ [4]_
- `graph-tool <https://graph-tool.skewed.de>`_ [5]_
- `igraph <https://igraph.org/python/>`_ [6]_
- `matplotlib <https://matplotlib.org>`_ [7]_
- `NetworKit <https://networkit.github.io>`_ [8]_
- `NetworkX <https://networkx.org>`_ [9]_
- `Pandas <https://pandas.pydata.org/>`_ [10]_
- `PyTorch Geometric <https://pytorch-geometric.readthedocs.io>`_ [11]_
- `Stanford Network Analysis Platform <https://snap.stanford.edu/snap/>`_ [12]_
- `StellarGraph <https://stellargraph.readthedocs.io>`_ [13]_
- `Teneto <https://teneto.readthedocs.io>`_ [14]_

For more information on specific packages, please refer to their respective documentation.
